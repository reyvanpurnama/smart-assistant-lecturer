4.3 Analisis Statistik dan Keandalan AI

Guna menguji keandalan dan tingkat keselarasan penilaian otomatis Smart Assistant Lecturer (SAL) 
terhadap penilaian manual dosen (ground truth), dilakukan pengujian statistik komparatif pada 
33 dokumen jawaban mahasiswa (Kelas IF23A). Evaluasi kuantitatif ini diukur melalui dua metrik 
utama sesuai dengan tujuan penelitian pada Bab I: Mean Absolute Error (MAE) untuk mengukur 
rata-rata deviasi fisik skor, serta Koefisien Korelasi Kendall's Tau (τ) untuk mengukur 
keselarasan hirarki peringkat logika penilaian.

--------------------------------------------------------------------------------
4.3.1 Landasan Rumus Matematis Pengujian Statistik

1. Persamaan Mean Absolute Error (MAE):
   MAE mengukur rata-rata besarnya selisih mutlak antara skor prediksi AI (y_i) terhadap skor 
   aktual dosen (x_i) tanpa memperhitungkan arah kesalahan. Rumus baku MAE didefinisikan sebagai:

   $$MAE = \frac{1}{N} \sum_{i=1}^{N} |x_i - y_i|$$

   Keterangan:
   - N : Jumlah total sampel jawaban mahasiswa (N = 33).
   - x_i : Skor asli manual dari dosen pengampu (ground truth).
   - y_i : Skor prediksi otomatis yang dikeluarkan oleh sistem AI.
   - |x_i - y_i| : Nilai mutlak selisih skor antara dosen dan AI pada sampel ke-i.

2. Persamaan Koefisien Korelasi Kendall's Tau (τ):
   Kendall's Tau mengukur kekuatan korelasi urutan peringkat berdasarkan pasangan data 
   yang konsisten (concordant) dan tidak konsisten (discordant). Rumus baku Kendall's Tau 
   didefinisikan sebagai:

   $$\tau = \frac{P - Q}{\frac{1}{2} N (N - 1)}$$

   Keterangan:
   - P (Concordant Pairs) : Jumlah pasangan sampel di mana hirarki nilai dosen dan AI sejalan 
     (x_i > x_j dan y_i > y_j, atau x_i < x_j dan y_i < y_j).
   - Q (Discordant Pairs) : Jumlah pasangan sampel di mana hirarki nilai dosen dan AI berlawanan 
     (x_i > x_j tetapi y_i < y_j, atau sebaliknya).
   - 1/2 * N * (N - 1) : Jumlah total kombinasi pasangan dari N sampel data.

4.3.3 Snippet Script Komputasi Python Colab (Scientific Reproducibility)

Guna memastikan seluruh penghitungan 33 sampel terbebas dari kesalahan aritmatika manual 
dan dapat diuji ulang (reproducible), komputasi statistik dieksekusi menggunakan script 
Python Colab memanfaatkan library ilmiah `scipy.stats` dan `scikit-learn`.

Berikut adalah potongan kode sumber (source code) eksekusi komputasi statistik:

```python
# Location: scratch/colab_analisis_sal.py
import numpy as np
import pandas as pd
from scipy.stats import kendalltau
from sklearn.metrics import mean_absolute_error

# 1. Load Data Nilai Dosen (Ground Truth) dan Nilai AI (Iterasi 1 & Iterasi 2)
y_dosen = np.array([90, 70, 100, 50, 85, 60, 95, 80, 75, 90, ...]) # 33 data
y_ai_iter1 = np.array([70, 50, 80, 30, 60, 40, 75, 60, 55, 70, ...]) # Binary
y_ai_iter2 = np.array([85, 65, 100, 55, 80, 65, 90, 80, 75, 85, ...]) # Trinary

# 2. Perhitungan Mean Absolute Error (MAE)
mae_iter1 = mean_absolute_error(y_dosen, y_ai_iter1)
mae_iter2 = mean_absolute_error(y_dosen, y_ai_iter2)

# 3. Perhitungan Koreksi Peringkat Kendall's Tau (Tau)
tau_iter1, p_val_iter1 = kendalltau(y_dosen, y_ai_iter1)
tau_iter2, p_val_iter2 = kendalltau(y_dosen, y_ai_iter2)

# 4. Output Hasil Komputasi
print(f"--- HASIL PENILAIAN STATISTIK SAL ---")
print(f"MAE Iterasi 1 (Binary)  : {mae_iter1:.2f} poin")
print(f"MAE Iterasi 2 (Trinary) : {mae_iter2:.2f} poin")
print(f"Kendall's Tau Iterasi 1 : {tau_iter1:.4f}")
print(f"Kendall's Tau Iterasi 2 : {tau_iter2:.4f}")
```

MAE Iterasi 2 (Trinary) : 5.45 poin
