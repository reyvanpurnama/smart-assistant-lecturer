--------------------------------------------------------------------------------
DRAF TEKS TAMBAHAN BAB II:

Guna memberikan gambaran eksplisit mengenai karakteristik soal esai logika yang dievaluasi dalam penelitian ini, instrumen evaluasi menggunakan kasus uji berupa tugas esai praktikum eksplorasi perintah Structured Query Language (SQL). Tugas ini dirancang oleh dosen pengampu untuk menguji kompetensi mahasiswa dalam mengeksekusi 10 operasi komputasi basis data yang mencakup pembuatan struktur basis data dan tabel, manipulasi data (insert, select, update, delete), serta penyesuaian struktur tabel (alter table). 

Secara spesifik, kunci jawaban yang seharusnya (ground truth konten) beserta rincian 10 aspek operasi yang diperiksa oleh dosen pengampu disajikan pada Tabel 2.2:

Tabel 2.2 Spesifikasi Soal dan Kunci Jawaban Acuan Dosen (Ground Truth Konten).
-----------------------------------------------------------------------------------------------------------------------------------------
No | Operasi SQL / Aspek Kriteria   | Deskripsi Instruksi Tugas                    | Kunci Jawaban Ideal / Sintaks Query Acuan Dosen
---|--------------------------------|----------------------------------------------|------------------------------------------------------------
1  | Pembuatan Database (Create DB) | Membuat database bernama 'universitas'       | CREATE DATABASE universitas;
2  | Pembuatan Tabel (Create Table) | Membuat tabel 'mahasiswa' dengan PK 'nim'    | CREATE TABLE mahasiswa (nim VARCHAR(10) PRIMARY KEY, nama VARCHAR(50), jurusan VARCHAR(30), angkatan INT, ipk DECIMAL(3,2));
3  | Pengisian Data (Insert Data)   | Memasukkan 3 data mahasiswa (Ali, Budi, Citra)| INSERT INTO mahasiswa VALUES ('12345', 'Ali Hasan', 'Informatika', 2021, 3.75), ('12346', 'Budi Santoso', 'Sistem Informasi', 2022, 3.60), ('12347', 'Citra Dewi', 'Teknik Komputer', 2020, 3.85);
4  | Penampilan Data 1 (Select All) | Menampilkan seluruh data mahasiswa           | SELECT * FROM mahasiswa;
5  | Penampilan Data 2 (Filter Teks)| Menampilkan mahasiswa jurusan 'Informatika'   | SELECT * FROM mahasiswa WHERE jurusan = 'Informatika';
6  | Penampilan Data 3 (Filter Angka)| Menampilkan mahasiswa dengan IPK > 3.7        | SELECT * FROM mahasiswa WHERE ipk > 3.7;
7  | Pembaruan Data (Update Data)   | Memperbarui IPK mahasiswa NIM '12346'        | UPDATE mahasiswa SET ipk = 3.8 WHERE nim = '12346';
8  | Penghapusan Data (Delete Data) | Menghapus data mahasiswa bernama 'Citra Dewi'| DELETE FROM mahasiswa WHERE nama = 'Citra Dewi';
9  | Tambah Kolom (Alter Add)       | Menambahkan kolom 'tanggal_lahir' (DATE)     | ALTER TABLE mahasiswa ADD tanggal_lahir DATE;
10 | Pembaruan Struktur Data        | Memperbarui tanggal lahir 3 data mahasiswa   | UPDATE mahasiswa SET tanggal_lahir = '2002-05-10' WHERE nim = '12345'; (3 query UPDATE terpisah)
-----------------------------------------------------------------------------------------------------------------------------------------

Melalui pemetaan pada Tabel 2.2, terlihat bahwa soal esai logika pemrograman memiliki karakteristik yang unik. Kebenaran jawaban tidak hanya dinilai dari kelancaran bahasa alami, melainkan dari presisi sintaksis SQL, ketepatan penggunaan tipe data, serta kebenaran klausa penyaringan data (WHERE).

DRAF TEKS TAMBAHAN BAB III:

3.2.3 Pengumpulan dan Pengolahan Data
Data penelitian yang digunakan berupa data sekunder (retrospektif) yang diperoleh dari arsip tugas akademik mahasiswa pada mata kuliah Basis Data Lanjut (IF204) di lingkungan Program Studi Teknik Informatika Universitas Muhammadiyah Bandung. 

Karakteristik spesifik dataset dan prosedur pengolahannya dijabarkan sebagai berikut:

1. Sumber Data & Ukuran Sampel Dataset:
   Dataset terdiri dari 33 dokumen jawaban esai praktikum mahasiswa retrospektif dari Kelas IF23A Angkatan 2023. Ukuran sampel ini (N = 33 dokumen) memenuhi asumsi kecukupan sampel statistik non-parametrik (N >= 30) untuk menguji korelasi dan deviasi skor (Islam, 2018; Fraenkel et al., 2019).

2. Rincian Rubrik Acuan Dosen (Ground Truth):
   Evaluasi dilakukan terhadap 10 aspek kriteria penilaian yang ditetapkan oleh dosen pengampu dengan total bobot akumulatif 100%. Setiap aspek memiliki bobot sebesar 10%, sebagaimana dirinci pada Tabel 3.2.

Tabel 3.2 Matriks Rincian Dataset dan Bobot Rubrik Penilaian Dosen.
-----------------------------------------------------------------------------------------------------------------------------------------
No | Aspek Rubrik Penilaian            | Nama Aspek Kriteria Penilaian                | Bobot Nilai (%) | Target Evaluasi Logika
---|-----------------------------------|----------------------------------------------|-----------------|----------------------------------------------------
1  | Rubrik 1                          | Pembuatan Database 'universitas'             | 10%             | Ketepatan query CREATE DATABASE & nama db
2  | Rubrik 2                          | Pembuatan Tabel 'mahasiswa' & Primary Key    | 10%             | Deklarasi tabel, kolom nim (VARCHAR), & PK
3  | Rubrik 3                          | Pengisian Data (Insert 3 Mahasiswa)          | 10%             | Sintaks INSERT & penggunaan kuotasi string NIM
4  | Rubrik 4                          | Query Read 1 (Tampilkan Semua Data)          | 10%             | Sintaks SELECT * tanpa filter
5  | Rubrik 5                          | Query Read 2 (Filter Jurusan Informatika)    | 10%             | Ketepatan klausa WHERE jurusan = 'Informatika'
6  | Rubrik 6                          | Query Read 3 (Filter Nilai IPK > 3.7)        | 10%             | Ketepatan klausa WHERE ipk > 3.7
7  | Rubrik 7                          | Query Update Data IPK                        | 10%             | Query UPDATE NIM 12346
8  | Rubrik 8                          | Query Delete Data Mahasiswa                  | 10%             | Query DELETE filter nama 'Citra Dewi'
9  | Rubrik 9                          | Alter Table (Tambah Kolom tanggal_lahir)     | 10%             | Sintaks ALTER TABLE ADD tipe DATE
10 | Rubrik 10                         | Update Data Tanggal Lahir                    | 10%             | Kelengkapan 3 query UPDATE tanggal lahir
-----------------------------------------------------------------------------------------------------------------------------------------
Total Bobot Akumulatif: 100%
