LAMPIRAN 1: NASKAH SOAL PRAKTIKUM DAN MODUL REFERENSI KRITERIA PENILAIAN DOSEN 
(KNOWLEDGE GROUNDING CONTEXT)

--------------------------------------------------------------------------------
MODUL PRAKTIKUM MANAJEMEN BASIS DATA
Materi: Konsep DBMS dan Perintah Dasar MySQL
Program Studi Teknik Informatika - Universitas Muhammadiyah Bandung
--------------------------------------------------------------------------------

A. Pendahuluan
Pada praktikum ini, mahasiswa diminta untuk membuat sebuah basis data sederhana untuk mengelola informasi mahasiswa. Praktikum mencakup:
1. Membuat database dan tabel.
2. Mengelola data menggunakan perintah dasar MySQL (CRUD: Create, Read, Update, Delete).
3. Studi kasus manipulasi struktur basis data (DDL & DML).

B. Perintah Dasar MySQL & Panduan Kriteria Penilaian Dosen (Knowledge Grounding)
Catatan Toleransi Evaluasi: Penilaian esai logika SQL tidak didasarkan pada kesamaan string tunggal secara absolut, melainkan mengevaluasi kesesuaian klausa, ketepatan tipe data, serta kebenaran logika operasi sesuai panduan rubrik terstruktur (3-Point Partial Credit Rubric: 0, 50, 100).

1. Membuat Database
   - Latihan: Buat database baru bernama 'universitas'.
   - Acuan Logika Dosen: Query `CREATE DATABASE universitas;`. 
   - Toleransi Rubrik:
     * Full Credit (100): Perintah DDL `CREATE DATABASE` dan nama database `universitas` ditulis tepat.
     * Partial Credit (50): Nama database tepat namun terdapat kesalahan penulisan kata kunci (misal `CREAT DATABASE`).
     * No Credit (0): Salah total atau tidak ada sintaks pembuatan database.

2. Membuat Tabel
   - Latihan: Buat tabel 'mahasiswa' dengan struktur kolom berikut:
     * nim (Nomor Induk Mahasiswa, VARCHAR(10), Primary Key)
     * nama (Nama Mahasiswa, VARCHAR(50))
     * jurusan (Jurusan Mahasiswa, VARCHAR(30))
     * angkatan (Tahun Angkatan, INT / YEAR)
     * ipk (Indeks Prestasi Kumulatif, DECIMAL(3,2))
   - Acuan Logika Dosen: Query `CREATE TABLE mahasiswa (nim VARCHAR(10) PRIMARY KEY, nama VARCHAR(50), jurusan VARCHAR(30), angkatan INT, ipk DECIMAL(3,2));`.
   - Toleransi Rubrik:
     * Full Credit (100): Struktur kolom, tipe data, dan deklarasi Primary Key `nim` lengkap dan tepat.
     * Partial Credit (50): Tabel berhasil dibuat namun keliru/lupa mendeklarasikan Primary Key pada kolom `nim`.
     * No Credit (0): Gagal membuat tabel atau tipe data salah total.

3. Menambahkan Data ke Tabel (Insert Data)
   - Latihan: Tambahkan 3 data mahasiswa berikut ke dalam tabel 'mahasiswa':
     * Data 1: NIM = 12345, Nama = Ali Hasan, Jurusan = Informatika, Angkatan = 2021, IPK = 3.75
     * Data 2: NIM = 12346, Nama = Budi Santoso, Jurusan = Sistem Informasi, Angkatan = 2022, IPK = 3.60
     * Data 3: NIM = 12347, Nama = Citra Dewi, Jurusan = Teknik Komputer, Angkatan = 2020, IPK = 3.85
   - Acuan Logika Dosen: Perintah `INSERT INTO mahasiswa VALUES ...`.
   - Toleransi Rubrik:
     * Full Credit (100): Ketiga baris data berhasil disisipkan dengan sintaks dan kuotasi string yang tepat.
     * Partial Credit (50): Sintaks `INSERT` ditulis namun terdapat kelalaian minor (misal lupa tanda petik tunggal pada string NIM).
     * No Credit (0): Tidak ada perintah `INSERT` atau data tidak diisi.

4. Membaca Data dari Tabel (Select Queries)
   - Latihan 4a: Tampilkan semua data mahasiswa.
     * Acuan Logika: `SELECT * FROM mahasiswa;`.
   - Latihan 4b: Tampilkan mahasiswa dari jurusan "Informatika".
     * Acuan Logika: `SELECT * FROM mahasiswa WHERE jurusan = 'Informatika';` (atau klausa `LIKE 'Informatika'`).
   - Latihan 4c: Tampilkan mahasiswa dengan IPK lebih dari 3.7.
     * Acuan Logika: `SELECT * FROM mahasiswa WHERE ipk > 3.7;`.
   - Toleransi Rubrik:
     * Full Credit (100): Perintah `SELECT` dan klausa penyaringan `WHERE` ditulis dengan kriteria yang tepat.
     * Partial Credit (50): Maksud penyaringan benar namun terdapat typo pada nama kolom atau operator perbandingan.
     * No Credit (0): Query tidak menampilkan data yang diminta.

5. Memperbarui Data (Update Query)
   - Latihan: Perbarui nilai IPK mahasiswa dengan NIM '12346' menjadi 3.8.
   - Acuan Logika Dosen: `UPDATE mahasiswa SET ipk = 3.8 WHERE nim = '12346';`.
   - Toleransi Rubrik:
     * Full Credit (100): Perintah `UPDATE`, klausa `SET`, dan filter `WHERE nim` ditulis tepat.
     * Partial Credit (50): Sintaks `UPDATE` ditulis namun keliru menentukan kolom target atau lupa klausa `WHERE`.
     * No Credit (0): Salah total.

6. Menghapus Data (Delete Query)
   - Latihan: Hapus data mahasiswa yang bernama 'Citra Dewi'.
   - Acuan Logika Dosen: `DELETE FROM mahasiswa WHERE nama = 'Citra Dewi';`.
   - Toleransi Rubrik:
     * Full Credit (100): Perintah `DELETE FROM` dan filter `WHERE nama` tepat.
     * Partial Credit (50): Perintah `DELETE` ada namun filter nama tidak spesifik.
     * No Credit (0): Salah total.

7. Mengubah Struktur Tabel dan Memperbarui Nilai (Alter Table & Update)
   - Latihan 7a: Tambahkan kolom 'tanggal_lahir' ber-tipe DATE pada tabel 'mahasiswa'.
     * Acuan Logika: `ALTER TABLE mahasiswa ADD tanggal_lahir DATE;`.
   - Latihan 7b: Masukkan nilai tanggal lahir pada setiap data di tabel 'mahasiswa'.
     * Acuan Logika: 3 query `UPDATE mahasiswa SET tanggal_lahir = ... WHERE nim = ...;`.
   - Toleransi Rubrik:
     * Full Credit (100): `ALTER TABLE ADD` dan pengisian tanggal lahir 3 mahasiswa lengkap.
     * Partial Credit (50): Kolom berhasil ditambah namun baru mengisi sebagian data tanggal lahir.
     * No Credit (0): Salah total.
